# 应用图标

图标沿用界面的墨绿色，以一个入口分流至两个环境的路由符号表达工具用途。薄荷绿色分支代表当前选中的环境；粗线条、大圆点和无文字设计保证小尺寸识别。

源图为 [app-icon.png](app-icon.png)，1254 × 1254，外部背景透明。由内置 imagegen 生成，使用 Tauri 官方图标生成器转换为桌面各平台资源；网页使用同一设计的 32 × 32 favicon。

## 生成提示词

为 NLab Easy Whistle 设计一个最终可用的 macOS 桌面应用图标，单个正方形图标，1024 x 1024，真正透明的外部背景。应用是本地 Whistle 代理规则与测试环境切换工具，界面主色 #24785a。设计概念：一个网络入口切换到两个环境。墨绿色圆角方形底板，轻微精致的立体厚度和顶部柔光，风格克制现代、接近 macOS 原生工具；大面积简洁，不要花纹。底板边缘保留约 9% 透明安全边距。中心为极简、粗而流畅的白色路由分支符号：左侧一个圆形入口，路径向右分成上下两条分支，右侧两个圆形终点；上方分支呈柔和偏白的浅绿色，下方选中分支和终点用鲜明但不荧光的薄荷绿，入口与主要路径白色。符号整体居中，大而醒目，圆点与线条足够粗，32px 仍能识别。保持简洁、平衡、可识别的独特轮廓，无字母、无文字、无箭头、无代码括号、无设备边框、无额外徽章、无复杂电路、无黑色外框、无 mockup、无背景场景、无水印。只输出单个图标，不输出展示板、多个方案或小图标网格。

## 接入位置

- `public/favicon.png`：网页图标，入口 `index.html` 引用。
- `src-tauri/target/release/bundle/macos/NLab Easy Whistle.app`：重新构建后包含新的 `icon.icns`。
