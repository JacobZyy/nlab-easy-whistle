# NLab Easy Whistle 方案

桌面交互原型和 Figma 设计已确认，正式 Web 应用按此方案实现。原型不连接真实 Whistle。

## 页面

一张规则表，每行代表原 Whistle 中的一组代理匹配规则。列为：启停、名称、匹配规则、环境、测试机、编辑/删除。名称默认空白，不参与匹配。

每行独立选择环境和测试机，允许不同规则同时指向不同机器。启停对应原规则是否注释，不因关闭而删除配置。规则顺序保持不变。

测试环境 IP 固定为 `192.168.170.88`，沙箱固定为 `10.9.31.195`。测试机录入一次后，所有行都可以从 select 中选择。匹配规则通过简单弹窗添加或编辑，每行输入一个 pattern，保持用户原文。

顶部只放 YAML 导入、导出和新增规则。操作列提供单行复制、编辑和删除。表格底部放 Whistle 地址设置与应用按钮，下方使用染色代码块预览规则，标题旁放“复制全部规则”。配置变更自动记忆，点击应用才写 Whistle。操作结果使用短提示。

用户给出的 `resBody://`、本地端口、`html://`、`log://` 等其他规则不纳入本工具的编辑范围。后续接入时保留这些原文，避免把环境切换工具扩展成通用 Whistle 编辑器。

## YAML

参考 Clash 的可读配置和文件导入导出方式，不增加订阅功能。

```yaml
version: 1
whistle:
  url: http://127.0.0.1:8899
machines:
  - jacobzy
  - sandboxjacobzy
rules:
  - name: ""
    enabled: true
    patterns:
      - '*/nlab_recycle_merchant'
      - '*/u/nlab_recycle_merchant'
    environment: test
    machine: jacobzy
  - name: ""
    enabled: false
    patterns:
      - '*/nlab_recycle_merchant'
      - '*/u/nlab_recycle_merchant'
    environment: sandbox
    machine: sandboxjacobzy
```

导入先校验，确认后替换本地配置，不自动应用。非法文件不覆盖现有数据。导出使用同一结构，支持重新导入。固定环境 IP 不重复写入 YAML。

浏览器使用 localStorage 记忆、文件选择器读取、Blob 下载。每组至少一个 pattern；环境限定 test/sandbox；测试机必须在已保存列表中；拒绝空值和会破坏单行规则的输入。

## 正式实现

采用 Vite SPA、TypeScript、Vue 3.6 Vapor、Tailwind CSS 4、daisyUI 5。daisyUI 提供 HTML/CSS，表格、select、input、toggle、button 和原生 dialog 的交互由 Vue 管理，无需 Nuxt UI / Reka UI 的 VDOM 互操作。

Vue 3.6 目前为 RC，正式落地时固定验证过的版本。原型使用 CDN，正式应用使用构建后的 CSS。单页不提前引入路由和 Pinia。

规则生成沿用用户提供的结构，一组一行。关闭的组加 `#`，以便重新启用：

```text
192.168.170.88 */nlab_recycle_merchant */u/nlab_recycle_merchant reqHeaders://{"Global-Route-Tag":"jacobzy"}
# 10.9.31.195 */nlab_recycle_merchant */u/nlab_recycle_merchant reqHeaders://{"Global-Route-Tag":"sandboxjacobzy"}
```

浏览器 fetch 请求当前页面同源的 HTTP 接口，由本地 Vite 服务转发到 Whistle，不使用 Tauri native HTTP。固定读取 `NLab Easy Whistle` 命名规则文件（URLSearchParams 编码 name），用 URLSearchParams 表单 POST `/cgi-bin/rules/add`，保存时自动勾选，再回读核对全文和启用状态。

只更新该文件中 `# BEGIN nlab-easy-whistle` 至 `# END nlab-easy-whistle` 的工具区块，保留区外手动文本。标记重复或不完整时停止写入。应用前读取最新文本；按实例规则优先级决定区块位置；全局规则禁用时显示提示。

Default 不读取、不写入、不迁移，文本和状态保持原状。页面下方增加实时生成文本预览和复制按钮，支持手动选中复制。

本地同源转发解决端口跨域，Whistle 桌面版本地鉴权仅由服务端核对官方进程文件后携带。status 接口可访问不能证明规则接口可读写。真实接入失败给具体错误，不伪报成功。

后续 Tauri 包同一 Web 页面，按需适配窗口、文件访问和本地 HTTP 服务。规则生成、状态、预览与 YAML 留在 Web；打包后的 HTTP 转发服务单独验证。

## 本次验收

- 每组独立启停，切换环境和测试机；规则增删编辑后刷新保留。
- YAML 导出再导入保持配置；非法配置不覆盖原数据。
- 原型不请求真实 Whistle；Figma 与原型保持相同布局。

正式接入时补充验证：其他 Whistle 规则保持原文，写后回读一致，失败不报成功。
